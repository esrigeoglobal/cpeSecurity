The upstream STIG for any STIG profile the SCAP Security Guide project is
developed under the DoD consensus model and DISA FSO Vendor STIG process,
serving as the upstream development environment for Red Hat Product STIGS.

As a result of the upstream/downstream relationship between the SCAP Security
Guide project and the official DISA FSO STIG baseline, users should expect
variance between SSG and DISA FSO content. For official DISA FSO STIG content,
refer to https://www.cyber.mil/stigs/.

1. *Packaging vs. Commercial Support Scope*
Although this compliance profile is bundled natively within the Red Hat SCAP Security Guide package, it operates entirely outside of standard enterprise service-level agreements (SLAs). Commercial support is unavailable, meaning Red Hat technical assistance does not cover its implementation, troubleshooting, or maintenance.

2. *Production Readiness and Validation Status*
This configuration is provided strictly as a reference baseline or example implementation. It carries no official endorsement for suitability in production environments. Organizations deploying this profile must independently validate, audit, and harden the configuration to ensure it aligns with their specific regulatory and operational security requirements.

3. *Community-Driven Upstream Maintenance*
All ongoing maintenance, updates, and troubleshooting for this profile are handled exclusively by the upstream OpenSCAP community on a best-effort basis. For official documentation, updates, and policy guidelines, refer to the OpenSCAP Security Guide Homepage.
